# FNA Data Model

## Purpose

`FNADataPayload` is the canonical structured representation of extracted client information before it is written into the Financial Needs Analysis workbook.

The schema must be strict so that extraction errors do not silently introduce unexpected fields.

## Root Model

```text
FNADataPayload
├── client_demographics
├── assets
├── liabilities
└── household_expenses
```

## Client Demographics

```text
client_demographics
├── full_name
├── id_number
├── tax_number
├── marital_status
├── employer
├── gross_monthly_income
└── net_monthly_income
```

### Validation

`id_number`:

- optional when it cannot be extracted;
- must contain exactly 13 digits when present;
- must pass a Luhn checksum;
- must be rejected if invalid.

Missing values must remain `null`.

## Assets

```text
assets
├── properties[]
├── vehicles[]
├── savings[]
└── unit_trusts[]
```

Each asset item should contain:

```text
description
current_value
institution
```

Examples:

```json
{
  "description": "Primary residence",
  "current_value": 1850000,
  "institution": null
}
```

```json
{
  "description": "Investment account",
  "current_value": 250000,
  "institution": "Allan Gray"
}
```

## Liabilities

```text
liabilities
├── mortgages[]
├── vehicle_finance[]
├── personal_loans[]
└── credit_cards[]
```

Each liability may contain:

```text
description
outstanding_balance
monthly_instalment
institution
```

Example:

```json
{
  "description": "Home loan",
  "outstanding_balance": 1120000,
  "monthly_instalment": 11200,
  "institution": "Example Bank"
}
```

## Household Expenses

```text
household_expenses
├── fixed_expenses[]
└── variable_expenses[]
```

Each item contains:

```text
description
monthly_amount
```

Example:

```json
{
  "description": "Electricity",
  "monthly_amount": 1800
}
```

## Derived Values

Derived values should be calculated by backend code, not generated by the AI model.

### Total Assets

```text
Total Assets =
Properties
+ Vehicles
+ Savings
+ Unit Trusts
```

### Total Liabilities

```text
Total Liabilities =
Mortgages
+ Vehicle Finance
+ Personal Loans
+ Credit Cards
```

### Net Worth

```text
Net Worth = Total Assets - Total Liabilities
```

### Total Household Expenses

```text
Total Household Expenses =
Fixed Expenses + Variable Expenses
```

### Monthly Disposable Income

```text
Monthly Disposable Income =
Net Monthly Income - Total Household Expenses
```

## Data Quality Principle

The model extracts.

The application validates.

The adviser verifies.

That separation is intentional.
